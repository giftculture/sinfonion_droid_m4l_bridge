# sinfonion-bridge

Makes Ableton Live follow an ACL Sinfonion's harmony: Sinfonion Harmonic Sync → DROID MASTER18 (`[sinfonionlink]`) → MIDI CC over USB → Max for Live master → per-track quantizers.

Spec: https://claude.ai/artifact/ENTWnPRtAmYPuNZEDVNeTc

| Path | What |
| --- | --- |
| `droid/sinfonion_bridge.ini` | DROID patch, copy to the MASTER18 SD card as `droid.ini` |
| `master/scales.json` | 108 Sinfonion scales, slots at root C (from DROID manual blue-7 pp. 119–121) |
| `master/sinf.master.amxd` | Max for Live master MIDI effect (generated by `tools/build_amxd.py`) |
| `master/sinf_decoder.js` | CC decoding, validation, slot lookup, `sinf.state` broadcast, Live scale sync |
| `master/live_scales.json` | Live's 35 scales and intervals, exported from Live 12 (April 2024) |
| `slave/sinf.slave.amxd` | Max for Live slave MIDI effect, one per track before the instrument |
| `slave/sinf_slave.js` | quantize core, select buttons, voice manager |
| `tools/extract_scales.py` | regenerates `scales.json` from the manual PDF |
| `tools/build_amxd.py` | regenerates both devices |

The `.js` files are ES5 so they load in Max's `js` object as well as Node.

## CC map (MASTER18 USB, channel 1)

| CC | Field | Encoding |
| --- | --- | --- |
| 19 | protocol version | 1 |
| 20 | root | 0–11 |
| 21 | scale | 0–107 |
| 22 | transpose | semitones + 64 |
| 23 | harmonic shift | −7..7 + 64 |
| 24 | chaotic detune | bipolar, 64 = 0 |
| 25 | link state | 0 / 127 |

All CCs are resent once a second.

## Master setup in Live

Put `master/sinf.master.amxd` on a MIDI track with MIDI From = the MASTER18 port, channel 1, Monitor In. Keep the device in `master/` so it finds `sinf_decoder.js` and `scales.json`. The audio engine must be running.
